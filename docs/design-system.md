# 残心 — デザインシステム / Design System

## デザイン原則

| 原則 | 意味 |
|------|------|
| **Calm** | 落ち着いた、静かな雰囲気 |
| **Minimal** | 必要なものだけを残す |
| **Spacious** | 呼吸できる余白 |
| **Japanese-inspired** | 和の美意識をベースに |
| **iOS-first** | iPhoneの手のひらに収まるUI |
| **Golden ratio aware** | 黄金比を意識したスケール |
| **Quiet but memorable** | 静かだが、印象に残る |

---

## 現代和の方向性

- 目指すのは「**静かな現代和**」であり、古風な和風テーマパークではない
- 刀・扇・墨・和紙・金箔・円相は、装飾ではなく**意味を持つモチーフ**として扱う
- 海外にも伝わる Japanese minimalism / wabi-sabi / calm journaling の感覚を、説明よりもUIの静けさで伝える
- 画面を和風記号で埋めず、余白・色・材質感・動きの抑制で日本的美意識を表現する

---

## 黄金比スケール

余白・サイズ・行間には、可能な範囲で以下のスケールを使う。

```
4 / 8 / 13 / 21 / 34 / 55 / 89
```

### 使用例

| 用途 | 値 |
|------|----|
| 画面左右余白 | 21px |
| カード padding | 21px |
| セクション間隔 | 34px |
| FABサイズ | 55px |
| エディタ上部余白 | 34px |
| 本文行間 | 1.618前後 |

---

## レイアウト数値方針

| 項目 | 方針 |
|------|------|
| 想定基準幅 | iPhone幅 375–430px を優先 |
| 画面左右余白 | 21px |
| リスト内カード間隔 | 13px |
| セクション間隔 | 34px |
| カード内タイトルと本文の間 | 8px |
| エディタ本文下部余白 | 89px（キーボード・FAB干渉を避ける） |
| 最小タップ領域 | 44px以上 |
| 推奨主要アクション | 55px前後 |
| FAB下部マージン | 21px + safe-area |
| 入力欄内 padding | 13px または 21px |

- キーボード表示時も本文入力が隠れにくい構成を優先する
- safe-area inset を前提に余白を調整し、PWA/Capacitor化しても窮屈にならないこと
- カードや入力欄を詰め込みすぎず、1画面に出す情報量を制限する

## モチーフの使い方

### 刀

**意味：** 集中・研ぎ澄ます・不要なものを削る・決断

**UI利用例：**
- 細い区切り線（`1px solid` / Faded Ink）
- 新規作成ボタンの抽象的アイコン
- メモカード左の縦アクセントライン

---

### 扇

**意味：** ひらく・広がる・呼吸・優雅さ

**UI利用例：**
- 空状態（Empty State）の薄い背景モチーフ
- お気に入りアイコンの造形ヒント
- 展開アニメーションの参考

---

### 円相

**意味：** 未完成の美・循環・余韻・静かな集中

**UI利用例：**
- 保存完了時の微細なアニメーション（小さな円が静かに描かれる）
- ロゴや透かし表現
- ローディング表現（派手にしない）

### 墨・和紙・金箔

**意味：** 静けさ・手触り・特別な印

**UI利用例：**
- 墨: 主要テキスト、細い線、静かなコントラスト
- 和紙: 背景とカードの基調、やわらかな明度差
- 金箔: お気に入りや大切な状態の最小限アクセント

**避けること：**
- 金を広範囲に使って豪華さを前面に出すこと
- 和紙テクスチャを強く出しすぎて可読性を下げること
- モチーフを複数同時に重ねて画面を騒がしくすること

## アニメーション方針

### 使用してよい

- `fade` — ゆっくりフェードイン/アウト
- `slow slide` — ゆっくりスライド
- `soft scale` — わずかな拡縮
- `breath-like motion` — 呼吸するような動き

### 避ける

- 派手なバウンド
- 意味のないキラキラ・パーティクル
- ゲーム的な演出
- 速すぎるトランジション（200ms以下は原則使わない）

### トランジション時間の目安

| 種別 | 時間 |
|------|------|
| 画面遷移 | 300–400ms |
| カード表示 | 200–300ms |
| 保存完了フィードバック | 400–600ms |
| ローディング | 呼吸感のあるループ |

---

## コンポーネント方針

- ボタンは少なく、役割を明確に
- アイコンは補助として使い、テキストを代替しない
- カードはシンプルな矩形ベース（過剰な装飾なし）
- 影（`box-shadow`）は控えめ、または使わない
- 角丸は小さめ（`4–8px`）または直角に近い形
- iPhoneで片手操作しやすい配置を優先する
- キーボード表示中も主要操作が迷子にならないこと
